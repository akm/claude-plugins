「節の表記が決まっている」という判断基準に違和感があります。分けるためにファイルが構造化されているかどうかが重要で、「節の表記が決まっている」のであれば既に構造化されていると言えると思います。

1. ファイルの内容を知っている ( 知らなければ unknown-content )
2. ツールが生成するものである ( 生成するのであれば generated )
3. ファイルの構造を知っている ( 知らなければ unknown-structure )
4. 分割できない ( 分割できないのであれば indivisible )
5. 分割すると意味が変わる可能性がある ( 可能性があるなら unstable )
6. 分割できる ( divisible )


unstable は 例えば CLAUDE.md で rules/ に分けることもできますが、その場合以前と待ったく同じ意味とは言えなくなる可能性があります。

構造化されている.js でも、 .ts から生成されるものは generated になりまずが、自前で書いた場合は divisible になります。あるいは vite などでソースコード群から生成される .html .js .css は ディレクトリ単位で generated となるので、必ずソースコード単位ではなく、プロジェクトの設定によって判断するためのパスが必要であるということです。
