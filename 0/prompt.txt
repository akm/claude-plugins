  ### 計画に影響する発見
  
  **A. origin の確認と、テストで GitHub に接続しない決定は、そのままでは両立しません。**
  - スクリプトが origin の URL を確かめるなら、テストの一時的なリポジトリの `remote.origin.url` は GitHub の URL にしておく必要があります。
