assignee の視点が入っていないのでそれを考慮したモデルにしてほしいです。
例えば GitHub Project X を3人で実行し、Aさん Bさんは  issue-dispatch を使って開発を行い、Cさんは使わずに開発するチームを想定してほしいです。いまの manager_name の決め方だと プロジェクトに 一つの管理セッションしか起動できませんが、Aさん Bさんが起動する issue-dispatch の 管理セッションが それぞれが assignee になっている issue を識別できるように `akm/3/A` `akm/3/B` のように名前を付ける必要があると思います。
