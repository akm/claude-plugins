# disk-usage-triage

ディスクの空きが足りないときに、利用者が設定したディレクトリを `du -d 1` と同じ深さで調べ、容量の大きい項目を、消してよいかの判定 (消してよい・確認が要る・残す) と一緒に一覧で示すプラグインです。利用者が選んだ項目から削除のシェルスクリプトを作り、利用者が中身を確認してから端末で実行します。Claude は削除のシェルスクリプトを実行しません。要望は Issue [#310](https://github.com/akm/claude-plugins/issues/310)、設計は計画 [docs/plans/2026-11-22-1630-feat-disk-usage-triage-plan.md](../docs/plans/2026-11-22-1630-feat-disk-usage-triage-plan.md) にあります。

**作成中**です。今の版 (0.1.0) のスキル `triage` は、設定 (調べるディレクトリ・プロジェクトのディレクトリ・時間の上限) を作る・変えるところまでを行います。調査・判定・一覧・削除のシェルスクリプトの作成・削除の後の比較は、計画の実装の単位ごとに足します。

## 使えるスキル

| スキル | すること |
| --- | --- |
| [triage](skills/triage/SKILL.md) | 設定が無ければ、調べるディレクトリとプロジェクトのディレクトリを質問して保存する。依頼があれば、設定を変える |

## 前提

- macOS の Claude Desktop の Code タブのセッションで使います。
- Python 3.11 以上 (標準ライブラリだけを使います)。スクリプトはコマンド `python3` で実行するので、`python3` が 3.11 より古い版を指すと、スクリプトは何もせずに終了し、スキルは版が古いことを示します。

## ファイル

設定などのファイルは、ディレクトリ `~/.claude/disk-usage-triage/` (保存先のディレクトリ) に保存します。中身はこのマシンのパスを指すので、ほかのマシンと同期・共有しないでください。ファイルの様式は [references/files.md](references/files.md) にあります。

## テスト

```bash
python3 -m unittest discover -s disk-usage-triage/tests
```
